## Tujuan Praktikum
Praktikum ini bertujuan untuk memahami dasar-dasar HTML dan membuat halaman web sederhana.

## Langkah Praktikum

### 1. Membuat Struktur Dasar HTML
Membuat file `index.html` dengan struktur dasar HTML yang terdiri dari `html`, `head`, dan `body`.

### 2. Membuat Heading dan Paragraf
Menambahkan heading menggunakan tag `h1` dan `h2` serta paragraf menggunakan tag `p`.

### 3. Memformat Teks
Menggunakan beberapa tag pemformatan seperti `b`, `i`, `strong`, `em`, dan `mark`.

### 4. Menambahkan Gambar
Menambahkan foto profil mahasiswa ke dalam halaman HTML menggunakan tag `img`.

File gambar disimpan di dalam folder `gambar`.

### 5. Menambahkan Hyperlink
Menambahkan link menuju halaman kedua dan website eksternal menggunakan tag `a`.

### 6. Membuat List
Membuat daftar menggunakan unordered list `ul` dan ordered list `ol`.

### 7. Membuat Halaman Kedua
Membuat file `halaman2.html` yang berisi materi HTML dasar dan link kembali ke halaman utama.

### 8. Menambahkan Komentar HTML
Menambahkan komentar menggunakan format `<!-- komentar -->` untuk memberikan keterangan pada kode.

## File Praktikum

- `index.html` - Halaman utama profil mahasiswa.
- `halaman2.html` - Halaman kedua.
- `gambar/` - Folder yang berisi foto profil.
- `README.md` - Dokumentasi praktikum.
