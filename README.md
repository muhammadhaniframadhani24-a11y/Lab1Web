## Tujuan Praktikum
Praktikum ini bertujuan untuk memahami dasar-dasar HTML dan membuat halaman web sederhana menggunakan struktur HTML.

## Langkah Praktikum

### 1. Membuat Struktur Dasar HTML
Membuat file `index.html` dengan struktur dasar HTML yang terdiri dari `<!DOCTYPE html>`, `<html>`, `<head>`, dan `<body>`.

### 2. Membuat Heading dan Paragraf
Menambahkan heading menggunakan `<h1>` dan `<h2>` serta paragraf menggunakan `<p>`.

### 3. Memformat Teks
Mencoba beberapa tag pemformatan teks seperti `<b>`, `<i>`, `<strong>`, `<em>`, dan `<mark>`.

### 4. Menambahkan Hyperlink
Menambahkan hyperlink menuju halaman kedua dan website eksternal menggunakan tag `<a>`.

### 5. Membuat List
Membuat daftar menggunakan unordered list `<ul>` dan ordered list `<ol>`.

### 6. Membuat Halaman Kedua
Membuat file `halaman2.html` sebagai halaman kedua dan menambahkan link untuk kembali ke halaman utama.

### 7. Menambahkan Komentar HTML
Menambahkan komentar menggunakan `<!-- komentar -->` untuk memberikan keterangan pada bagian kode.

## File Praktikum

- `index.html` - Halaman utama profil mahasiswa.
- `halaman2.html` - Halaman kedua berisi materi HTML dasar.
- `README.md` - Dokumentasi praktikum.
